# Portfolio

Personal portfolio of Devendra Singh Baghel, full-stack developer.

Live: https://devendrabaghel.vercel.app

## Stack

Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui, MDX. Hosted on Vercel.

## Running Locally

Requires Node.js 22 or newer.

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Production build
npm run build

# Run linter
npm run lint
```

## Folder Structure

- `app/` — App Router routes, layouts, metadata, and dynamic OG/icon handlers.
- `components/` — UI components (`components/ui/` for base elements, plus section components).
- `data/` — Typed data files for experience, projects, and skills.
- `content/case-studies/` — Deep-dive technical case studies written in MDX.
- `lib/` — Shared utility functions and site constants.
- `public/` — Static assets including resume PDF and images.
- `docs/` — Project documentation, specifications, design tokens, and architectural decisions.
